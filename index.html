1. Client/Server

Definition of Client

A client is a computer or software application that requests services or resources from a server. A web browser is an example of a client.

Definition of Server

A server is a computer or software system that provides services, resources or data to clients over a network.

2. Components of Web Application

View Layer

The View Layer is responsible for the user interface. It displays information to the user and accepts user input.

Business Layer

The Business Layer contains the main business logic of the application and processes data.

Data Access Layer

The Data Access Layer communicates with databases and handles storing, retrieving, updating and deleting data.

3. Types of Web Content

Text

Text includes headings, paragraphs, articles and other written information.

Images

Images include photographs, logos, icons and illustrations.

Audio

Audio includes music, podcasts and voice recordings.

Video

Video contains moving visual and audio information.

Animation

Animation creates the appearance of movement on a webpage.

4. HTTP and HTTP Request

Definition of HTTP

HTTP stands for HyperText Transfer Protocol. It is used for communication between web clients and servers.

HTTP Request and Response

An HTTP request is sent by a client to request a resource. The server processes the request and sends an HTTP response.

Working of HTTP Communication

The client sends a request to the server. The server processes the request and sends a response back to the client. The browser then displays the result.

5. Dynamic Web Pages

Definition

A dynamic web page is a webpage whose content can change based on user interaction, database information or other conditions.

Characteristics

  • Content can change dynamically.
  • Can interact with databases.
  • Supports user interaction.
  • Can provide personalized content.

Examples

Examples include online shopping websites, social media, online banking and web-based email.

6. Application Servers

Definition

An application server provides an environment for running and managing web applications.

Purpose

It provides services required for executing applications, managing resources and handling business logic.

Major Services

  • Transaction management
  • Security management
  • Database connectivity
  • Session management
  • Application deployment

7. Web Security

Definition

Web security refers to practices used to protect websites, web applications, servers and users from security threats.

Importance

Web security protects sensitive information, prevents unauthorized access and maintains the safety of web applications.

Basic Security Measures

  • Use HTTPS for secure communication.
  • Use strong passwords.
  • Keep software updated.
  • Use authentication and authorization.
  • Validate user input.
  • Encrypt sensitive data.
